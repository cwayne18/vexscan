# Output and reporting

`--format text` is for reading; `--format summary` is for a one-screen count;
`--format json` is for keeping; `--format sarif` is for a code-scanning
dashboard; `--format fixplan` is for acting.

- **[Reports and formatting](./reports)** — the summary, the text report, remediation, colour.
- **[Severity and filtering](./severity-and-filtering)** — severity sources, `--severity`, `--fixed-only`, `--triage`.
- **[VEX and vendor sources](./vex-sources)** — `--vexhub`, `--distro-feeds`, `--prefer-vendor`.
- **[Contributing VEX back](./vex-output)** — `--vex-out`, merged reports, CSAF.
- **[JSON, SARIF, and gating](./machine-formats)** — machine formats and `--fail-on`.
